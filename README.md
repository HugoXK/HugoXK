I build systems where agents improve themselves. At Huawei 2012 Laboratory I work across the stack: large-scale RLHF post-training on Ascend NPU clusters, multi-agent scheduling for scientific discovery, and recursive self-improvement (RSI) loops where agents evolve their own skill libraries under strict train/validation/test discipline.

## What I'm working on

- **RLHF at cluster scale** — core modules of GRPO and DAPO, long chain-of-thought sequence packing, and stability validation on Ascend NPUs.
- **Agent systems** — a pluggable DAG-based multi-agent scheduler with configurable node types and dependencies for scientific discovery.
- **Recursive self-improvement** — rollout, failure-driven skill induction, and top-K frontier selection over versioned, auditable skill libraries; exploring island populations, MAP-Elites archives, and tree search.
- **Self-generated evaluation** — letting agents drive their own curriculum.
